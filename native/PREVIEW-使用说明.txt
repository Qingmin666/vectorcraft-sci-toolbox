VectorCraft 科研定制版 0.2.0-preview.1

这是本地开发预览，基于官方 VectorCraft 0.10.0 单独编译。尚未作为第二版正式发布。

使用：
1. 双击 VectorCraftSCI.exe。
2. 在右侧“属性 / 图层 / 库”旁点击“科研组图”；也可从“窗口”菜单打开。
3. 新建文档并导入图片，或打开 examples 中的原生示例。
4. 选择要处理的原始图片或对象，设置列数、行列间距，点击“排列所选对象”。
5. 设置字号、字体、起始编号和偏移，点击“添加 / 更新标签”。重复操作更新同一组关联标签。
6. 每次操作可一次撤销；正常保存为 .vectorcraft 保留对象和标签的可编辑性。

单位为 pt。编号 1 对应 A，26 对应 Z，27 对应 AA。标签目前是黑色，定位在对象左上角；负偏移可把标签放到对象外侧。
不要同时选择原图和工具箱标签，也不要同时选择组合和其内部对象；单次最多 200 个对象。

本预览仅包含网格和可编辑子图标签；其他首版工具正在迁移。它不需要 API Key、Python 工具箱或后台网页服务。
原生面板支持浮动与停靠，参数随设置保存。定制版使用独立的 VectorCraftSCI 设置目录，不迁移官方版设置。

本程序未签名，也不是上游官方发行。此预览包暂不应直接上传为正式 GitHub Release。
