VectorCraft 科研定制版 0.2.0-rc.2

基于官方 VectorCraft 0.10.0 单独编译的第二版候选。尚未发布为正式 GitHub Release。
双击 VectorCraftSCI.exe，在右侧“属性 / 图层 / 库”旁打开“科研组图”，也可从“窗口”菜单打开。
每个分区可折叠；向下滚动查看其余功能。正常使用不需要 API Key、Python 服务或首版工具箱。

建议顺序：导入图片 → 设置实际标定 → 排图 → 添加标签/边框/比例尺 → 按需要添加 ROI 或处理通道 → 保存。

1. 排图与尺寸
选择原图、文字或组合，指定列数和间距；宽高留空表示不改变。保持比例时只填一个尺寸。
支持自动识别行列、同行等高、总宽度及左右齐边。按行、水平、垂直、选择或图层顺序排列，可反转。
尺寸和间距可从选择对象读取；对齐支持整体边界、首对象和画板参考；分布支持边缘及中心。

2. 标签、位置、边框
标签支持 A/a/A)/a)/(A)/(a)/数字、粗体、字体、四角锚点和偏移。重复操作更新已有标签。
可直选文字重编号，或筛选/排除文字。启用实时偏移后可调整已有标签，结束拖动形成一次撤销。
复制粘贴绝对/相对位置，支持画板参考、九宫格锚点、坐标偏移及反向；数量不一致须显式启用对应选项。
边框支持颜色、线宽、虚线和与原图编组。移动原图后重新更新标签/边框。

3. 配色
文字、边框、比例尺和 ROI 均可调用原生取色窗口，支持 HEX、最近12色和文档纯色色板。
参数取色只改科研设置；添加/更新操作才应用到画稿。原生普通填充/描边取色仍保持原行为。
配色库支持分组、保存、编辑、删除，左键选参数颜色，右键复制 HEX/RGB；“填充所选形状”是单独的显式操作。
共23套：18套来源可追溯配色和5套 SCI 原创方案。原创方案不是期刊指定色表。

4. 实际标定与比例尺
FOV 表示图像覆盖的真实视野宽/高，不是画布尺寸或打印 DPI。请填写真实数值和单位。
可读取链接 TIFF 中明确的 OME/ImageJ 标定；无标定、普通 DPI 或嵌入后丢失元数据的图片须手动输入。
横尺需要真实宽度，竖尺需要真实高度。支持 nm/um/mm/cm/m/inch、文字、粗体、颜色、角落和内缩。
“仅保存标定”不生成尺；长度0可隐藏。重复操作更新已有比例尺。批量默认保留各图已有标定。
自动保存默认关闭，启用后参数变化会延迟应用到当前选择；不需要时保持关闭。

5. ROI 放大图
为原图添加一个或多个区域，X/Y/宽/高采用0–1比例，可旋转区域、设置颜色和各区比例尺。
也可先画矩形，选中图片和矩形，读取矩形为区域。倍率0表示自动齐边；可选择放大图方位及连接线。
创建的是可编辑图片副本、裁剪、边框和引导线。自动同步跟随源图/区域变化，并保留手动调整后的放大图位置。
ROI 继承裁切后的真实视野；每区可覆盖比例尺长度/单位。保存 .vectorcraft 保留关联。

6. 可编辑伪彩与通道合并
七种 RGB 分量着色：红、绿、蓝、青、品红、黄、灰度/原分量。使用黑底与 Darken 叠层，保留源像素。
灰度选项保留原RGB分量，不将彩色图转为亮度灰度。可替换为组合或在右侧保留原图生成副本，再次操作可改色。
Screen：选择2–7个显示尺寸相同的通道 → 读取所选通道 → 开关/改色 → 合并，保留原图。
它是 Screen 混合，不是像素配准或定量加法；应先合并再旋转。用于科研定量时仍需采用原始数据和合适分析方法。

所有文档尺寸/间距/偏移为 pt；真实标定单位另设。单次最多200对象，ROI最多32区域。
不同时选择父组合与内部对象，不选择隐藏/锁定对象；绘图操作可撤销重做。
定制版使用独立 VectorCraftSCI 设置目录。保留原官方版和旧候选版即可分别启动。
本程序未代码签名，也不是上游官方发行。许可和配色来源见 licenses 与 source/native。
使用 .vectorcraft 保存完整可编辑结构；PNG 用于输出预览，不保留编辑结构。
