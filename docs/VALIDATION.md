# v0.1.0 验证记录

验证日期：2026-10-15。平台：Windows 11 x64，VectorCraft 0.10.0。源码检查与单元测试使用 Python 3.14.6，最低支持版本声明为 3.10，但尚未逐版本运行。使用专用测试窗口及独立配置，未修改用户原始图稿。

## 实际桌面冒烟测试

`scripts/smoke_desktop.py` 通过 **27 项检查**。完整结果保存在 [`examples/smoke-report.json`](../examples/smoke-report.json)。

- 确认为真实桌面接口，而非 MCP 后台文档。
- 合成图片的网格间距、逐对象保持比例缩放、顶端对齐和净间距。
- 每项操作合并为一次撤销，撤销/重做恢复对象边界。
- 两对象位置交换、绝对位置粘贴、相对位置参考对象与偏移。
- 可编辑子图标签创建、文字样式更新和不重复创建。
- 可编辑边框不填充，重复运行只更新已有边框。
- 保存原生画稿、导出实际 PNG、重开后保留图片/文字和标签关联。
- 旋转组合、带矩形裁剪蒙版图片的排版与撤销。
- 非法尺寸不产生编辑、过期选择被拒绝、锁定或空选择被拒绝。
- 执行中发生明确引擎拒绝时，之前的部分编辑回滚。

示例图片由程序合成，不是实验数据。边界比较容差为 0.08 pt。

## 算法与本机服务测试

`python -m unittest discover -s tests -v` 的 **16 项测试通过**，验证坐标变换、网格、净间距、比例和标签编号，以及页面服务的会话令牌、Host/Origin、预设保存和任意路径拒绝。还验证不变尺寸不产生撤销记录、过期选择/修订和未知命令拒绝。JavaScript 通过 `node --check`。

## 人机界面及打包检查

浏览器面板已实际打开并执行网格排图、标签更新和画稿预览。Windows 便携 EXE 已独立启动，验证专用桌面窗口启动、原生示例打开、四张图片选择读取、无变化操作不产生撤销记录、预设保存和实际 PNG 预览。记录见 [packaged-smoke.json](packaged-smoke.json)。工具箱关闭接口已验证，不会关闭 VectorCraft 画稿。

面板已检查桌面及窄屏布局；截图为本机实际面板，不是设计稿。Windows EXE 尚未代码签名；运行前可核对同一发行版的 SHA256SUMS.txt。

## 尚未验证或不支持

- 不承诺其他 VectorCraft 版本、macOS/Linux 或所有字体组合兼容。
- 未进行大量真实论文图稿和长期连续操作测试。
- 未用操作系统鼠标逐个验证原生画布中的选择行为。
- 不支持父组合和其后代同时选择、零尺寸对象、隔离编辑。
- 不支持软件内停靠面板、原图变动自动跟随、比例尺、放大图、伪彩或通道合并。
- 网络中断后不确定状态采取暂停编辑处理；未声称拥有崩溃恢复或完全事务隔离。
