VectorCraft 科研定制版 0.2.0-rc.1

这是基于官方 VectorCraft 0.10.0 单独编译的第二版候选，尚未作为正式 GitHub Release 发布。

双击 VectorCraftSCI.exe。在右侧“属性 / 图层 / 库”旁点击“科研组图”，也可从“窗口”菜单打开。
可打开 examples 里的 .vectorcraft 示例，或新建文档并导入自己的图片。每个分区可折叠；向下滚动可查看位置、边框和预设。

排图与尺寸：选择原始图片、文字或组合，设置列数和行列净间距。宽/高留空表示不变；保持比例时只填其中一项。可单独统一尺寸，也可与网格排图一起完成。
对齐与等间距：展开分区，按整体边界或第一个对象对齐；水平/垂直分布使用对象间的净间距。
子图标签：支持 A/a/A)/a)/数字，字号、字体、#RRGGBB 颜色、四角锚点和偏移。负偏移可放到原图外侧。重复操作更新原有标签。
位置管理：绝对/相对位置复制粘贴；两个对象交换位置。相对模式以第一个排序对象为参考，粘贴时保持新参考对象原位。位置记录在重启后清空。
图片边框：添加/更新独立可编辑的矩形边框，线宽和颜色可设置。
命名预设：保存、载入、删除常用参数；最多 32 个，重启后恢复。

所有尺寸、间距、偏移均为 pt。每项画稿操作可一次撤销/重做。正常保存为 .vectorcraft 保留原图、文字、标签及边框的可编辑性。

不同时选择原图与其标签/边框，也不同时选择父组合与内部对象。单次最多 200 个对象；隐藏、锁定、空对象或零宽/零高对象不可处理。
旋转/组合/裁剪对象按轴向几何边界排布。标签和边框不自动跟随移动；移动原图后再次运行对应更新操作。
接口选择顺序不等同于鼠标点击顺序，需要确定排列顺序时选择按行、水平或垂直排序。

定制版使用独立的 VectorCraftSCI 设置目录，不迁移官方版设置。无需 API Key、Python 环境或首版网页工具箱；正常启动不开放控制端口。
本机已验证主要迁移功能、保存重开和设置恢复；跨机器兼容与科研内容正确性应结合自己的文件检查。

本程序未代码签名，也不是上游官方发行。原有程序与资源许可见 licenses；源代码接入补丁和独立科研模块见 source/native。
source/scripts/build_native_windows.ps1 可取得固定上游源码并应用补丁重建；source/scripts 下提供专用测试窗口的验证脚本。
