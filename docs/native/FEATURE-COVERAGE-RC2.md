# RC2 功能覆盖与边界

依据用户提供的 2.5.0 离线源码包功能审计独立实现。仅原生第二版，第一版保持原状。
本表描述代码覆盖，不能替代最终程序验证；通过记录另见 VALIDATION-RC2.md。

|功能|RC2 对应实现|
|---|---|
|固定列/自动识别排图|固定列、识别当前行列、同行等高、左右齐边和总宽度|
|排序|按行、水平、垂直、选择、图层顺序及反转|
|对齐|六方向、双轴居中，整体/首对象/画板参考|
|分布|净间距、固定两端、六种边缘/中心等分、读取间距|
|尺寸复制|读取宽高、独立宽高与按比例粘贴|
|位置复制|绝对/相对、画板参考、九宫格锚点、偏移、反向及显式数量匹配|
|位置交换|九宫格参考点交换，保留个体尺寸|
|子图标签|大小写、括号、数字、粗体、字体、偏移、直选重编号及实时偏移|
|选择效率|文字筛选和排除|
|图片边框|线宽、参数取色、虚线、自动编组、关联更新|
|配色|原生参数取色、最近颜色、文档纯色、可管理配色分组|
|比例尺|真实视野、单位、横竖、文字样式、批量保留标定、可选自动保存|
|TIFF标定|经典/BigTIFF、双字节序、OME/ImageJ明确标定；普通DPI不作为标定|
|ROI创建|数值/矩形区域、多区域、旋转、颜色、线型、倍率和方位|
|ROI关联|源图/区域/输出关联，自动更新、保存布局、撤销重做|
|ROI比例尺|按裁切视野继承，可按区覆盖长度与单位|
|伪彩|七种RGB分量、可编辑黑底/原图/Darken叠层、保留像素、重复改色|
|通道合并|2–7通道Screen、通道开关/改色、保留原图、陈旧列表拒绝编辑|

## 明确差异

- 23套配色由18套许可可追溯色表和5套SCI原创组成。未复制 ggsci 的 GPL 色表，原创方案不冒称期刊指定色表。
- 科研模块为中文界面。上游已有多语言不代表新增科研面板已经完成各语言翻译。
- 伪彩的灰度选项保留原RGB分量；不将彩色图转换成亮度灰度。Screen不是像素配准或定量加法。
- 原始单通道着色要求未旋转、100%不透明和正常混合；通道合并在旋转之前进行，结果随后可旋转。
- ROI应从原图创建，不在关联放大图上再创建嵌套关联。普通标签/外边框需在移动原图后再次执行更新。
- 自动标定需要可访问的原始链接TIFF及明确元数据；嵌入图片不能凭打印DPI推断真实尺寸。
- 用户修改画稿后，通道列表须重新读取，避免误用陈旧参数。所有示例均为合成测试图，不是实验数据。
